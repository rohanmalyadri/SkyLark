# Slides

| File | What it is |
|---|---|

| [`skylark-slides.pdf`](skylark-slides.pdf) | A 21-page PDF of the same slides, for when the HTML can't be opened. Opens in the browser on GitHub. |

## Opening the HTML deck

GitHub shows the HTML as source, so download it first: open the file, choose **Download raw file**, then
open it in Chrome or Edge. It works offline.

- Arrow keys or space to move, **P** for the presenter view with speaker notes.
- The live product is at [skylarkgo.in](https://www.skylarkgo.in); the deck opens it in a new window.

Use the slides for the parts we can't show live. Every number on them comes from the repository or the
running product; sample data is labelled as sample.
