# Interview notes

Notes from every person we spoke to outside the classroom while building Skylark. One file per person,
written from [`_template.md`](_template.md), named `YYYY-MM-DD-role.md`
(for example `2026-09-14-final-year-cse-student.md`).

Rules we follow:

- Only real conversations. Every file has a date, the person's role and how we met them.
- Quotes are their own words, written down at the time. Paraphrases are marked as paraphrases.
- We record answers that went against our idea as carefully as the ones that agreed with it.
- No full names, phone numbers or emails unless the person agreed. A role and a first name or initials is enough.

> Looking for an example of finished notes? See [`samples/`](samples/README.md). Those are **illustrative samples,
> not real interviews**, and are kept separate from the real notes below.
